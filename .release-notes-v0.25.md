# v0.25 — Primera release pública de StrategicAudit Pro (SCAUDIT)

Plataforma de auditoría estratégica con motor de IA: copiloto conversacional con
streaming, intelligence OSINT/CT, RUM propio (Core Web Vitals en campo), panel
admin de uso y una base de endurecimiento (RLS, CI, e2e) de 725 commits
(2026-04-12 → 2026-10-26).

## ✨ IA — Copiloto con streaming SSE (Sprint 1)

- **Streaming end-to-end**: `/api/ai/copilot` acepta `stream:true` y responde SSE
  con fallback de proveedor; UI con render incremental, **Stop** real vía
  `AbortController` e historial local de conversación.
- **Telemetría A2**: `ttft_ms` y `streamed` por proveedor, con probe SSE vivo en e2e.
- **Anti-monodependencia**: cadena OpenRouter con failover a **Groq** y **Gemini**
  (endpoints OpenAI-compatibles, circuit breaker propio, piso de 512 `max_tokens`
  para modelos reasoning) — verificado en vivo con OpenRouter en 429.
- **Integridad del chat**: sidebar conectado al endpoint real, prompt grounded,
  semántica de errores honesta (sin pasos falsos ni espera artificial), canned
  response honesto para 0 hallazgos, redacción de PII y tests de anti-inyección.

## 📊 RUM propio — Core Web Vitals en campo (H-09 / TD-23)

- **Self-RUM en producción**: beacon `vitals.js` (web-vitals@3.5.2) auto-instrumenta
  el propio sitio; proyecto dedicado + beacon token anti-DB-bloat; fail-closed sin env.
- **Attribution build**: los eventos traen `lcpElement` y la descomposición del LCP
  (`lcpTTFB` + `lcpResourceLoadDelay` + `lcpResourceLoadTime` + `lcpElementRenderDelay`)
  — en campo se confirmó que el LCP del landing es render delay puro del hero.
- **Gate de campo TBT→INP** en REQ-002/H-10b; hardening de la ruta de telemetría
  (404/503 auto-diagnósticos en vez de 500 opaco, FK 23503→404).

## ⚡ Rendimiento

- First-load de `/`: **−17,3% raw / −17,2% gzip** (supabase fuera del first-load).
- Cache inmutable para `/_next/static` y particionado mensual de `uptime_logs`.
- **DROP de `uptime_logs_legacy`** con export previo y ledger de paridad (CHANGE-007 (b)).

## 🗄️ Base de datos

- **Caché L2 de IA en Postgres**: conector tenant-scoped, TTL 1h e invalidación
  on-write; `cacheScope` por tenant en los 4 call-sites (fix de aislamiento).
- Índices compuestos de findings/audits por proyecto/fecha; particionado de logs.
- **CHANGE-007** completo: paquete de aprobación con T4 verificado en prod.

## 🛡️ Seguridad y calidad

- Guard de superficie RLS con baseline regenerado; RLS fase 2 + policies de escritura.
- **Gate a11y axe-core** en Playwright; CSP endurecida (nonce en el loading boundary).
- E2E: historial del chat, probe SSE con tolerancia a outage, worker dedicado anti
  agotamiento de Chrome, 5 baselines visuales versionadas.

## 🧭 Panel admin

- **`/admin/usage`** con KPIs de uso y gráfico diario (server actions + reducer puro).

## 🔧 Notas para quien instala

- Requiere Node 20+, Supabase (Postgres + RLS), Vercel y claves de IA opcionales
  (OpenRouter recomendada; Groq/Gemini como failover). Ver `.env.example`.
- El beacon RUM es opt-in: sin `NEXT_PUBLIC_RUM_PROJECT_ID` no se renderiza.
- La hoja de ruta pública fechada vive en el dashboard (bloque colapsable) y el
  CHANGELOG completo en [`docs/CHANGELOG.md`](https://github.com/StrategicConnex/StrategicConnexAudit/blob/main/docs/CHANGELOG.md).
