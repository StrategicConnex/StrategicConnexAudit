👤 Manual de Usuario Final

Guía de uso completa y extremadamente detallada de la plataforma SCAUDIT Pro, pensada para analistas de seguridad, consultores SEO y administradores de infraestructura.

¿Qué es SCAUDIT Pro?

SCAUDIT Pro es una plataforma enterprise de inteligencia de red y monitoreo de superficie de ataque. Combina:

  • Inteligencia cibernética: escaneo de DNS, WHOIS, GeoIP, SSL/TLS, OSINT y 34+ herramientas.
  • Auditoría técnica SEO: crawlers, Core Web Vitals, integración GSC/GA4.
  • Seguridad continua: SIEM con alertas multi-canal, detección de anomalías y adversary simulation.
  • Reportes: informes IA con gráficos y diagramas, PDF white-label.
Resumen rápidoSi ya tienes cuenta: ve a Nuevo Proyecto → ingresa un dominio → Escanear. En menos de 2 minutos tendrás un score de seguridad con hallazgos y recomendaciones.

2. Login y autenticación

2.1 Iniciar sesión con Magic Link

  1. Ve a /login.
  2. Ingresa tu email. La plataforma valida en tiempo real: rechaza correos desechables, temporales y typosquatting.
  3. Presiona Enviar Magic Link.
  4. Revisa tu bandeja de entrada y haz clic en el enlace recibido.
  5. Serás redirigido automáticamente al dashboard.
Sin contraseñasSCAUDIT usa Magic Link (OTP por email). No hay contraseñas que recordar ni que se puedan robar.

2.2 Rate limit del login

EndpointLímiteBypass
validate-email40 req/60s por IPEmails en AUTH_EMAIL_ALLOWLIST
auth callback10 req/60s por IPEmails en AUTH_EMAIL_ALLOWLIST
Límite de intentos alcanzadoSi ves este mensaje, espera 60 segundos. Para cuentas con acceso frecuente, agrega el email a AUTH_EMAIL_ALLOWLIST (el owner ya está incluido por defecto).

3. Dashboard (Overview)

El dashboard es el Command Center de todos tus proyectos:

  • Project Cards: cada proyecto muestra health score, última auditoría, estado de integraciones y métricas en vivo (latencia, uptime).
  • Score Gauge: medidor visual del health score (0-100) con clasificación.
  • Benchmarking: radar chart que compara tu proyecto vs la industria (percentiles P25/P75/P95).
  • Attack Surface Graph: grafo interactivo de dominios ⇄ IPs ⇄ certificados.
  • Métricas rápidas: clicks orgánicos, impresiones, CTR y posición promedio (si GSC está conectado).

4. Gestión de proyectos

4.1 Crear un proyecto

  1. Haz clic en Nuevo Proyecto (esquina superior derecha).
  2. Completa: nombre del proyecto, dominio (ej. tuempresa.com).
  3. Opcional: conecta Google Search Console y Google Analytics 4.
  4. Presiona Crear.

4.2 Acciones sobre un proyecto

AcciónDescripción
Ejecutar auditoríaCrawler SEO profundo: títulos, metadatos, H1/H2, estructura.
Escaneo de inteligenciaCorre las herramientas de inteligencia sobre el dominio.
DesactivarDetiene el monitoreo sin borrar datos.
ExportarPDF white-label y CSV de keywords.

5. Inteligencia cibernética

La pestaña Intelligence es el corazón técnico de la plataforma.

5.1 Ejecutar un escaneo

  1. Selecciona el proyecto en el selector superior.
  2. Elige el objetivo (dominio, IP, URL) o usa el dominio del proyecto.
  3. Selecciona herramientas del catálogo o usa Escaneo Completo (todas las aplicables).
  4. Presiona Ejecutar.

5.2 Herramientas disponibles (34+ executors)

CategoríaHerramientas
DNSlookup (A/AAAA/MX/TXT/NS/SOA), dnssec, propagation, zone, DMARC, SPF
Redping, traceroute, reverse DNS, GeoIP, ASN, CDN, WAF, reverse IP
Websiteheaders, security headers, TLS/SSL scan, robots.txt, redirects, cookies, CSP, tech stack
EmailSPF, DMARC, DKIM, email breach
OSINTWHOIS, shodan, reputation IP (blacklists), subdomain discovery

5.3 Resultados del escaneo

  • Hallazgos: cada uno con severidad (info/low/medium/high/critical), confianza y recomendación.
  • Badge MITRE: cada hallazgo se mapea a técnicas MITRE ATT&CK (ej. T1583.001).
  • Mapa Geo: activos con coordenadas GeoIP.
  • Score de seguridad: 0-100 calculado por el risk engine.
  • Historial: pestaña History con timeline de cambios DNS/WHOIS.

6. Reportes IA y PDF

6.1 Generar reporte con IA

  1. Ve a la pestaña Reports.
  2. Selecciona proyecto y período.
  3. Presiona Generar con IA.
  4. La barra de progreso avanza (tope 90% mientras genera; 100% solo cuando el informe está listo).
Contenido del informe IAEl reporte ejecutivo incluye: resumen ejecutivo, análisis de rendimiento (tabla), diagnóstico técnico de salud (LCP/INP/CLS), plan de acción priorizado con diagrama Mermaid y gráficos de barras con los datos de rendimiento.

6.2 Exportar PDF white-label

  1. Configura branding (logo + colores) en Settings.
  2. Desde el dashboard o ReportsTab, presiona Exportar PDF.
  3. Se genera el PDF con donut chart de severidad, bar chart de scores y página de assets.

7. Monitoreo y rendimiento

7.1 Live Streaming Metrics

Barra flotante (abajo a la derecha en Intelligence) que se expande al hover y muestra en vivo (cada 15s):

  • Uptime %: últimos 5 checks en ventana de 24h.
  • Latencia promedio (ms).
  • Findings críticos/high: conteo de severidad.

7.2 PerformanceTab

  • Core Web Vitals: LCP, INP, CLS, TTFB, FCP.
  • Lighthouse scores con gráficos.
  • Anomalías detectadas (Z-score) en latencia y error rate.

8. Keywords SEO

  • Seguimiento de posiciones de keywords objetivo.
  • Volumen de búsqueda, CPC y competencia.
  • Exportación CSV de keywords desde datos reales de BD.

11. Configuración y API Keys

11.1 SettingsTab

  • Perfil y preferencias de la cuenta.
  • Branding de reportes (logo, colores) para PDF white-label.
  • Integraciones (GSC, GA4, Bing).
  • Preferencias de idioma y notificaciones.

11.2 API Keys Dashboard (/settings/api-keys)

  • Stat cards: Active Keys, Used This Week, Total Requests, Expiring Soon.
  • Crear key con expiración (30/90/365 días o Never). La key se muestra una sola vez.
  • Tabla con búsqueda, filtros y mini-bars de uso.
  • Revocar keys con confirmación.

12. PWA e instalación

  1. Abre SCAUDIT en Chrome/Edge (desktop o Android).
  2. Presiona el botón Instalar SCAUDIT en el header del dashboard.
  3. La app se instala en modo standalone (ventana propia, sin barra del navegador).
  4. Funciona offline: si pierdes conexión, la offline page se muestra con el diseño SCAUDIT.

13. Cambio de idioma

  • Usa el LanguageSwitcher (es/en) en el header.
  • La preferencia se guarda en cookie y se recuerda entre sesiones.
  • Detección automática: cookie → Accept-Language → default es.

14. Preguntas frecuentes

PreguntaRespuesta
¿El informe IA se queda en 35% o 100% sin mostrar?Está corregido: la barra tope en 90% y llega a 100% solo con informe real. Si persiste, revisa la consola de red (timeout 110s) o configura OPENROUTER_API_KEY.
¿Cómo creo un proyecto en la pestaña Adversary?Usa el selector de proyectos (igual que en Intelligence). Si no aparece, créalo primero en Overview.
¿Cómo veo el historial de cambios de un dominio?En IntelligenceTab → pestaña History o en /security/audit (pestañas WHOIS Alerts / DNS Alerts).
¿La sección DNS del scan aparece vacía?Era un bug de keys mayúsculas/minúsculas, ya corregido con lecturas tipadas en scan-response.ts.
¿Puedo usar mis propios plugins?Por ahora el marketplace incluye 8 plugins oficiales. El mecanismo de ejecución soporta plugins custom vía registry.
¿Hay límite de escaneos?Sí, rate limiting por IP con Upstash Redis (headers RateLimit-* en las respuestas).
¿Dónde veo las alertas de seguridad?En /security/audit: pestañas Events, SIEM Alerts, WHOIS Alerts y DNS Alerts.
¿Necesitas ayuda?Consulta el Manual de Funcionamiento Técnico para detalles de arquitectura o revisa el manual de instalación para despliegues.
